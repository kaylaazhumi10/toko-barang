## Deskripsi Singkat
Aplikasi ini memungkinkan pengguna untuk melihat daftar produk dalam bentuk tabel, melihat rincian detail dari masing-masing produk, serta memasukkan data kode, nama, kategori, dan harga untuk menyimpan produk baru ke dalam sistem.
